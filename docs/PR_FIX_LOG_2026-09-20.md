# AskMate PR 수정 로그

## 작업 일시
- 2026-09-20

## 문제 요약
- 프론트엔드 템플릿과 JS 연결이 비어 있어 실제 브라우저 동작을 검증할 수 없는 상태
- `auth_sidebar.js`의 문자열 escape 로직이 문법적으로 위험한 상태
- `chat.html`과 JS 사이의 DOM 식별자가 불일치하여 화면 이벤트가 동작하지 않는 상태
- 백엔드 API는 아직 미구현 상태이므로 프론트는 현재 mock/예외 흐름을 전제로 정리해야 함

## 조치 내용
1. `backend/app/templates/chat.html`에 실제 채팅 UI 구조와 로그인/회원가입 모달을 추가
2. `backend/app/static/js/chat.js`에서 입력 검증, 메시지 렌더링, 로딩/오류 상태 흐름을 정리
3. `backend/app/static/js/auth_sidebar.js`에서 UI 상태 전환, 모달 처리, 비로그인/로그인 흐름을 정리
4. 문서 기록 파일을 남겨 작업 범위와 의도를 추적 가능하게 정리
5. 백엔드 파일은 원래 규칙에 따라 건드리지 않고 프론트엔드 범위만 유지

## 검증
- `python3 -m compileall backend/app` 실행 완료
- Python 문법 검증 기준 통과
- 현재 변경 범위는 프론트엔드(UI/JS/템플릿)로 제한

## 참고
- 본 문서는 작업 기록과 회고를 남기기 위한 파일이다.
- 실제 백엔드 구현은 별도 담당 브랜치/PR에서 처리한다.
- 추가 버그 발견 시 같은 폴더에 별도 로그 파일을 추가한다.
